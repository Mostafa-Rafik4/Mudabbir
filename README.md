# Arabic Dashboard

A responsive, right-to-left (RTL) Arabic dashboard built with HTML, CSS, and CSS Grid. 
The project presents key information in clear, organized cards and charts.

## Project Overview

 The main goal was to build a complete dashboard page in Arabic that:

- Displays the main information clearly in organized sections
- Uses **CSS Grid** to arrange the layout in rows and columns
- Supports right-to-left (RTL) reading direction for Arabic text
- Matches the design, images, and steps given in the assignment

## Features

- Full Arabic interface with RTL layout
- Responsive grid layout that adapts to desktop, tablet, and mobile screens
- Clearly separated dashboard cards and sections
- Consistent fonts and spacing for easy reading
- Navigation menu with links to each section of the dashboard

## Technologies Used

- **HTML5** for the structure of the page, with `lang="ar"` and `dir="rtl"` set on the root element
- **CSS3** for styling, colors, and spacing
- **CSS Grid** for the main page layout and the arrangement of dashboard cards
- **Flexbox** for aligning items inside cards and the navigation bar
- **Google Fonts:** IBM Plex Sans Arabic, which displays Arabic text clearly
- **Font Awesome 6:** Icons used in the navigation and dashboard cards


## How CSS Grid Is Used

- The **main page** is divided into a grid of columns and rows, so the header, sidebar, and content areas are placed in defined positions.
- The **dashboard cards** are arranged in a grid that adjusts the number of columns based on the screen width.
- Grid areas are named so the layout is easy to read and change.
